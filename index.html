📋 Local Setup Instructions

💻 Workstation (Laptop) — Magnum 12B v2

1. Install LM Studio (or koboldcpp / text-generation-webui) on the laptop and download a Magnum-v2-12B GGUF quant (Q4_K_M or Q5_K_M is a good size/quality balance).

2. Load the model, then start LM Studio's local server (Developer → "Start Server"). LM Studio defaults to port 1234 and speaks the OpenAI-compatible /v1 API this app expects.

3. Find the laptop's LAN IP (macOS: System Settings → Wi-Fi → Details; Windows: ipconfig) and enter http://<that-ip>:1234/v1 above. Make sure the phone/tablet running ZetaForge and the laptop are on the same Wi-Fi network, and allow the app through the laptop's firewall.

4. Tap "🔌 Test Connection" — it should say ✅ Reachable once the server is running.

📱 On-Device (iPhone Pro / iPad Air) — Llama 3.1 8B Stheno

1. Install a local GGUF runner on the device (e.g. an llama.cpp-server-based app such as "LM Pocket", or any app that exposes an OpenAI-compatible local server).

2. Download a Llama-3.1-8B-Stheno-v3.4 GGUF quant — Q4_K_M for the iPhone Pro profile, or the smaller Q3_K_M for the iPad Air profile if you want a more conservative memory/context footprint. Load it and start the local server on port 8080 (or whatever port your runner uses).

3. Leave the URL as http://127.0.0.1:8080/v1 (127.0.0.1 = this same device — nothing leaves the device). Adjust the port to match your runner if it differs.

4. If ZetaForge is served over HTTPS, some browsers block a page from fetching plain http:// localhost. If the Test Connection fails only in that scenario, run ZetaForge itself locally (e.g. from Claude Code / a local dev server) on the device, or use a runner that offers a local HTTPS option.

⚡ Smart Auto-Routing pings the Workstation profile (500ms timeout), then falls back to the current device's profile — automatically picking iPad Air vs iPhone Pro's context cap based on the device — and finally falls back to Gemini if neither answers. Useful if you move between your desk and your phone/tablet without wanting to switch this dropdown by hand.
